COMO SUBIR ESTA ATUALIZACAO NO GITHUB (pelo navegador, sem terminal)
====================================================================

1) Abra: https://github.com/supremapix/Alumimec-Estruturas-Met-licas

2) Clique em  "Add file"  >  "Upload files".

3) Descompacte este ZIP no seu computador. Voce vera a pasta
   "alumimec-atualizado". ABRA essa pasta e arraste TODO o CONTEUDO
   de dentro dela (nao a pasta em si) para a area de upload do GitHub.
   O GitHub aceita subpastas (components, pages, public, scripts, lib).

4) Em "Commit changes", escreva por exemplo:
      SEO/GEO/AIO + favicons + pre-render estatico
   e clique em "Commit changes".

5) O deploy (Vercel/Bolt) reconstroi sozinho.
   O comando de build continua sendo:  npm run build
